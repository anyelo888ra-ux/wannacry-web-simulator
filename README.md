# ☣️ WannaCry Web Simulator

An interactive, 100% harmless web-based simulation of the iconic **WannaCry (WNCRY)** ransomware UI. Designed exclusively for cybersecurity awareness, educational demonstrations, and UI experiments within web desktops like **Nexus WebOS**.

> ⚠️ **Disclaimer**: This project contains **NO malicious code**, encryption payloads, or exploits. It is purely a visual and functional front-end simulation (HTML/CSS/JS) built for educational and research purposes.

## ✨ Features

* **Authentic UI**: Recreates the classic dark red WannaCry decryptor layout, countdown timers, and payment instructions.

* **Live Timers**: Real-time JavaScript counters simulating price hikes and key destruction limits.

* **Simulated File Locker**: Interactive visual demonstration of mock file status updates.

* **Educational Kill-Switch**: Implements a simulation toggle based on Marcus Hutchins' famous domain kill-switch discovery.

* **Safe Sandbox**: Operates entirely in-browser with zero impact on the host operating system.
